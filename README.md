# 工学云周报月报生成工具
> 一键生成工学云实习周报、月报，支持多专业自定义，适配汽车制造等工科实习

## ✨ 功能
- 自动生成实习周报、月报文本
- 支持自定义专业、岗位、实习内容
- 多端支持：Android / Windows / 鸿蒙 / iOS
- 模板可自行修改调整
